# 🐍 Python Engineering Portfolio & CS50P Implementations

A structured collection of Python implementations, problem sets, and unit test suites completed as part of **Harvard University's CS50's Introduction to Programming with Python (CS50P)**.

Demonstrates core competence in modular software design, object-oriented programming (OOP), automated unit testing (`pytest`), regex parsing, file I/O pipelines, and third-party API integration.

---

## 🛠️ Key Technical Modules & Highlights

### 1. Automated Testing & Code Quality (`pytest`)
* **Unit Test Suites (`test_*.py`):** Wrote comprehensive unit tests for edge cases, assertion handling, and input boundaries using `pytest`.
* **Featured:** `test_fuel.py`, `test_plates.py`, `test_bank.py`, `test_working.py`, `test_response.py`.

### 2. Object-Oriented Programming (OOP)
* **Classes & Encapsulation:** Implemented custom classes, validation decorators (`@property`, `@setter`), and operator overloading.
* **Featured:**
  * `jar/`: Custom `Jar` class with capacity tracking, bounds enforcement, and error raising.
  * `seasons/`: Date arithmetic and string transformation using classes and datetime modules.

### 3. API Consumption & Data Handling
* **`bitcoin.py`:** Interacts with live REST APIs (CoinDesk API), parses dynamic JSON payloads, and computes real-time conversions with command-line argument validation (`sys.argv`).

### 4. Regular Expressions & Validation (`re`)
* **`numb3rs/`:** Validates IPv4 addresses using strict regular expressions.
* **`watch.py` & `response.py`:** Extracts YouTube embed URLs from raw HTML strings and validates email formats using regular expression parsing.

### 5. File I/O & Data Transformation
* **`scourgify.py`:** Cleans, reformats, and splits multi-column CSV files.
* **`shirt.py` & `shirtificate.py`:** Automated image overlay and dynamic PDF certificate generation using the Pillow (PIL) and FPDF libraries.
